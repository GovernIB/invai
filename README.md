***Descripció***

INVAI és el sistema d'inventari d'aplicacions corporatives de la CAIB (Illes Balears). Permet
mantenir el catàleg d'aplicacions amb la seva informació de desenvolupament, tecnologia,
proveïdor, i els sistemes i bases de dades associats, i gestionar per a cada aplicació les
persones responsables i autoritzades (amb el seu tipus de responsabilitat o autorització), a més
dels catàlegs de suport (empreses, persones, categories, unitats administratives).
